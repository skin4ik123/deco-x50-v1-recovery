# Post-recovery progress — 2026-11-01

[Русский](#русский)

The tested device is an ordinary **TP-Link Deco X50 EU hardware v1.0**, recovered with the stock 1.6.7 image described in this repository. These results concern that unit. They do not establish support for every X50 revision or firmware build.

## Confirmed on the owner's device

| Milestone | Observed result |
| --- | --- |
| Stock recovery | Owner confirmed successful recovery with the length-field-only 1.6.7 image |
| Privileged file service | The service reported UID and GID 0; a nonce-only RAM file write and readback succeeded |
| Command execution | A fixed `id` probe returned `uid=0(root) gid=0(root)` through an owner-authenticated session, without UART |
| Cache restoration | The original volatile web cache was restored and verified byte for byte |
| Critical backups | The owner-run client reported `CRITICAL_BACKUPS_VERIFIED: 13/13` |

The command execution report was supplied as a private JSON result together with the console output. The backup completion is evidenced by the owner's console output from a client that compares downloaded data with a separate on-device checksum. The private flash dumps have not been independently inspected or published here.

## Backup coverage

The 13 partitions total **16,515,072 bytes (15.75 MiB)**:

| MTD | Name | Bytes |
| --- | --- | ---: |
| 0 | `0:SBL1` | 524,288 |
| 1 | `0:MIBIB` | 524,288 |
| 2 | `0:BOOTCONFIG` | 262,144 |
| 3 | `0:BOOTCONFIG1` | 262,144 |
| 4 | `0:QSEE` | 1,048,576 |
| 5 | `0:DEVCFG` | 262,144 |
| 6 | `0:CDT` | 262,144 |
| 7 | `0:APPSBLENV` | 524,288 |
| 8 | `0:APPSBL` | 1,310,720 |
| 9 | `0:ART` | 1,048,576 |
| 10 | `0:TRAINING` | 524,288 |
| 13 | `0:ETHPHYFW` | 524,288 |
| 14 | `factory_data` | 9,437,184 |

The client streamed bounded reads from read-only MTD devices to the owner's phone over verified HTTPS. A separate on-device SHA-1 read was compared with the downloaded data, and local SHA-256 values were recorded. The original web cache was restored before each data read and checked again afterward.

This backup contains ECC-corrected MTD data without NAND OOB information. Its scope excludes the two 42 MiB OS slots (`rootfs` and `rootfs_1`) and `runtime_data`. A whole-flash backup and a tested restore procedure remain unfinished.

## What the root result means

The result demonstrates repeatable privileged command execution while the existing stock service remains available to the authenticated owner. The probe did not install a permanent shell service or a new account. Its temporary cache change was reversed. Empty nonce files can remain in RAM until reboot.

The post-recovery probes and backup client did not write flash, change boot selection, or install OpenWrt. This is separate from the earlier stock recovery operation, which necessarily flashed an OS image.

## Remaining work

- Check whether the stock kernel can boot an appropriate OpenWrt image from RAM without UART.
- Validate the active boot slot, regional Wi-Fi board data and image layout against this specific unit.
- Complete the required backups and a practical recovery plan before an installation attempt.

**A working UART-less OpenWrt installation has not yet been demonstrated.** The [separate X50 v1 OpenWrt port](https://github.com/Oein/Deco-X50-Firmware-Unpack/blob/main/openwrt/README.md) documents a first installation using UART and RAM boot. Root access is progress toward another route, not proof that its installation steps can be run unchanged on stock firmware.

## Русский

На восстановленном **Deco X50 EU V1.0** владелец подтвердил запуск `id` с результатом `uid=0(root) gid=0(root)` без UART. Перед этим отдельно проверены чтение файлов и запись небольшого временного файла в ОЗУ. Исходный кэш веб-интерфейса после проверок восстановлен и сверен побайтно.

Следующий клиент успешно сохранил и проверил **13 критических разделов — 16 515 072 байт (15,75 MiB)**: загрузочные компоненты, выбор загрузки, окружение загрузчика, ART с калибровками и `factory_data`. Данные передавались на телефон ограниченными порциями по проверенному HTTPS; контрольная сумма сравнивалась с отдельным чтением на устройстве.

Это данные MTD после коррекции ECC, без NAND OOB. Два системных слота по 42 MiB и `runtime_data` в эту копию не входят. Полная резервная копия и проверенная процедура обратного восстановления ещё не готовы.

Постоянная SSH-консоль и новая учётная запись не создавались. В ходе этих проверок флеш-память и параметры загрузки не изменялись. Пустые временные файлы могут оставаться в ОЗУ до перезапуска.

**OpenWrt этим способом ещё не установлен.** Далее нужно проверить возможность загрузки из ОЗУ, региональные данные Wi-Fi, разметку образа и вариант восстановления без UART. Результат относится к проверенному устройству; переносимость на другие ревизии и версии прошивки не доказана.

Проверки на устройстве выполнил владелец **@skin4ik123**, анализ и утилиты подготовлены совместно с **ChatGPT / Codex**. Архивы разделов, ключи, пароли и личные данные в этот отчёт не включены.
