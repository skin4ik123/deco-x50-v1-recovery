# Deco X50 V1 — TP-Link 1.6.7 HTTP Recovery

Готовый BIN для восстановления **Deco X50 EU V1.0** через старый HTTP recovery на `http://192.168.0.1`. Владелец подтвердил успешное восстановление устройства этим образом.

Основа: официальная **TP-Link 1.6.7 Build 25031412 Rel. 48241**. Изменены только три байта внешнего поля длины; подписанное содержимое и RSA-подпись сохранены. Это независимый recovery-релиз, а не официальный выпуск TP-Link. `v1.0.0` — версия нашего пакета восстановления, версия системы — `1.6.7`.

## Скачать и прошить

1. В разделе **Assets** скачайте **`Deco_X50_V1_1.6.7_TPLink_HTTP_Recovery.bin`**. Архивы **Source code** содержат исходники, их загружать в роутер не нужно.
2. Подключите один Deco напрямую к компьютеру Ethernet-кабелем. Установите на компьютере IPv4 `192.168.0.2`, маску `255.255.255.0`.
3. Войдите в recovery, удерживая Reset при включении питания, согласно инструкции TP-Link: https://www.tp-link.com/ca/support/faq/2958/.
4. Откройте `http://192.168.0.1`, выберите скачанный BIN и запустите восстановление. Дождитесь завершения записи и перезагрузки, сохраняя питание.
5. После запуска штатной системы при необходимости выполните обычный сброс кнопкой Reset и настройте Deco. Верните компьютеру автоматическое получение IP.

Этот файл предназначен именно для страницы **U-Boot HTTP recovery**, а не обычного обновления через приложение Deco или рабочую веб-панель. Подтверждённый случай — **EU X50 V1.0**; совместимость с другими ревизиями и загрузчиками не проверена. Использование остаётся экспериментальным за пределами подтверждённого случая.

## English

Ready-to-upload **TP-Link stock 1.6.7 Build 25031412 Rel. 48241** image for the legacy **Deco X50 EU V1.0 U-Boot HTTP recovery** page at `http://192.168.0.1`. Successful recovery with this exact image was confirmed by the device owner in the reported case.

Download the **BIN under Assets**, connect one Deco directly by Ethernet, set the PC to `192.168.0.2/24`, enter recovery as described in the TP-Link FAQ above, and upload the BIN. Keep power connected until writing and reboot complete. Restore DHCP on the PC afterward. Use the normal Reset procedure after stock firmware starts if a settings reset is needed.

Only the unsigned length field changes (three bytes). Signed firmware contents and RSA signature are preserved. This is an independent recovery package, not an official TP-Link release. Other hardware revisions and bootloaders remain unverified. Use the U-Boot recovery page, not the normal Deco app/web updater. **`v1.0.0` is the recovery package version; `1.6.7` is the TP-Link firmware version.**
